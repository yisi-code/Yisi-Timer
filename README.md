# yisi-定时工具

给 Windows 用的桌面小工具：按分类管理上下班打卡提醒、开机提醒和定时关机。提醒是全屏卡片，
带农历、干支年和生肖；到点弹出来，按 ESC 或点按钮关掉，没理会就隔几秒再弹一次，直到你确认。

**下载最新版：<https://github.com/yisi-code/Yisi-Timer/releases/latest>**
（GitHub 慢时可以用 Gitee 镜像：<https://gitee.com/yisi-code/yisi-timer/releases>，仓库名在 Gitee 上显示为「yisi-定时工具」，网址路径是 `yisi-timer`，内容相同）

## 能做什么

| 功能 | 说明 |
|---|---|
| 分类管理 | 提醒按分类分区显示（上下班提醒、开机拦截、定时关机只是建议的分类名，可以自己增删改）。每个分类里「＋ 新增」挑一个预设或自定义，按住卡片可以拖动排序、拖到别的分类就是换分类 |
| 两种触发类别 × 三种时间 | 触发类别分「定时」和「开机」；时间分「每日」「工作日」「自定义（勾星期）」，两边自由组合。定时再加具体时点（如 17:30，多个用逗号隔开）；开机在登录后弹一次 |
| 生效时段 | 每条规则都能限定只在某个时间段内触发（如 08:00–08:40），留空就是全天；支持跨零点。时段外不触发，开机提醒在时段外也不会弹 |
| 全屏提醒 | 深空、晨雾、暮色三套主题，可自定义强调色与字号；卡片显示提醒标题、内容、补充说明、角标、按钮文案，底部是当前日期时间、星期、农历、干支年、生肖（可在设置里逐项开关、改格式） |
| 首页计时 | 首页顶部一条计时区域，每秒刷新，格式跟随「设置 → 时间显示格式」，中英文都支持 |
| 稍后提醒 | 需要时给单条规则开「稍后提醒」，卡片上会多一个「稍后 N 分钟」，间隔按规则单独设置 |
| 定时关机 | 到点先弹全屏提醒，倒计时（每条规则单独设置秒数）结束才真正关机；这期间点「取消关机」就不关，点「立即关机」立刻关 |
| 开机自启 | 一键写启动文件夹快捷方式；有开机/定时规则却没开自启时，首页会提示并给一个「立即开启」按钮 |
| 托盘常驻 | 单击托盘图标打开首页；关窗口是收进托盘，退出在设置里或托盘右键菜单里 |
| 中英切换 | 设置里切换中文 / English，界面文案与提示即时更新（自己填的规则名、内容不翻译） |
| 自动更新 | 「关于」里「检查更新」：同时问 GitHub 与 Gitee 取最新版本，下载安装包后核对 ECDSA 签名、大小与 SHA256，通过才安装并自动重启 |
| 卸载干净 | 设置页或「应用和功能」里卸载：删配置、开机自启、桌面快捷方式、注册表登记与整个程序目录，不留残余 |

> 早期版本尝试过「关机前拦截」（拦下系统关机、先弹打卡提醒）。在 Windows 11 上系统不会把关机
> 消息送到后台常驻程序，兜底轮询也赶不上，实测拦不住，所以整块功能已经移除——现在只在你自己
> 配的「定时关机」时关机，而且一定先弹提醒、有倒计时、可以取消。

## 下载与安装

1. 打开 [最新版本](https://github.com/yisi-code/Yisi-Timer/releases/latest)，下载安装包
   （发版里的资产名是 `yisi-timer-<版本>.exe`，因为平台会改写中文文件名；下载后可以随便改名再安装）；
   同一个发版里还有它的 `.sig` 签名清单，程序更新时会自动下载并校验。
2. 双击安装包，选一个安装位置（默认 `%LOCALAPPDATA%\Programs`）。安装程序会在你选的位置下再建一个
   `倚肆工具` 文件夹，程序、配置都放在里面；可选「创建桌面快捷方式」「开机自动启动」。
3. 打开后先在首页「＋ 新建分类」建几个分类，再到分类里「＋ 新增」添加提醒。
4. 配置就在程序目录里：`reminders.json`（规则）、`categories.json`（分类）、`reminder_options.json`
   （显示格式、主题、语言、字号）。升级安装不会覆盖已有配置；想恢复默认就删掉这几个文件。

也可以静默安装（给批量部署用）：

```powershell
.\安装 yisi-定时工具.exe --silent --dir="D:\Apps"
```

装完是 `D:\Apps\倚肆工具\yisi-定时工具.exe`；无声卸载用 `yisi-定时工具.exe --uninstall --yes`。

## 从源码构建

需要 Windows 与 Python 3.14（只用标准库 + PyQt5 + zhdate + cryptography，没有其它运行时依赖）。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install PyQt5 zhdate cryptography pyinstaller
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean yisi-定时工具.spec
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean "安装 yisi-定时工具.spec"
```

直接跑源码看效果：`.venv\Scripts\python.exe warningwork.py`；调试时加 `--dry-run` 或环境变量
`WARNINGWORK_DRY_RUN=1`，所有关机动作只写日志、不真执行。

`打包.ps1` 是维护者本机用的脚本（里面是本机的 Python 与密钥路径），不随仓库分发。

## 更新签名

发版时的安装包用 P-256 私钥签一份清单，程序里内置对应公钥，只接受签名、大小与 SHA256 都对得上的包：

```powershell
python -I 发布签名.py keygen <密钥目录>                                 # 首次：生成密钥对
python -I 发布签名.py sign <私钥.pem> "安装 yisi-定时工具.exe" 1.2.0      # 发版：生成 .sig
python -I 发布签名.py verify <公钥.txt> "安装 yisi-定时工具.exe"           # 核对
```

私钥不进仓库（保存在维护者本机的密钥目录里）。清单格式与校验细节见 `发布签名.py` 顶部说明。

发版时把安装包与 `.sig` 一起上传；客户端按**扩展名**挑资产（`.exe` / `.sig`），
所以资产名用 ASCII 最稳（GitHub 会把中文名改写成 `yisi-.-<版本>.exe`）。

## 目录

```text
warningwork.py            主程序：界面、规则调度、提醒窗口、关于与更新
installer.py              安装程序：选目录、写默认配置、建快捷方式、登记卸载信息
yisi-定时工具.spec        主程序打包配置
安装 yisi-定时工具.spec    安装程序打包配置（内嵌主程序与默认配置）
defaults/                 安装时写入的默认配置（空规则、空分类、默认选项）
发布签名.py               发版签名工具（keygen / sign / verify）
```
